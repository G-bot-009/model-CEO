Admin Usage — API & การจับคู่เอเจนต์

เพิ่ม API key ได้หลายตัว แล้วเลือกว่าเอเจนต์ไหนใช้ key ไหน — เอเจนต์ที่ใช้คนละ key จะทำงาน พร้อมกันได้ และ แยกนับ token แยกบิล ตาม key คีย์ถูกเก็บในเครื่อง (ไฟล์ agents.db ที่ไม่ขึ้น git) และไม่ถูกส่งกลับไปแสดงแบบเต็ม

เลือกข้อความทางซ้ายเพื่อตอบ

รูปแบบ JSON: {platform, sender, text, kind:"chat"|"comment", thread}

เชื่อมครั้งเดียว — AI โพสต์/อ่าน-ตอบคอมเมนต์/แชตให้ทั้งหมด · เลือกแพลตฟอร์มที่อยากเชื่อม จะกี่อันก็ได้

ใช้ OAuth จริง (BYO app) — สร้าง OAuth App ในพอร์ทัลของแต่ละแพลตฟอร์ม วาง Client ID/Secret แล้วกดยินยอม (บางแพลตฟอร์มต้องผ่านรีวิวก่อนโพสต์จริงได้)

ทุกคนที่ทักมา + AI สรุปว่าต้องการอะไร

ส่งข้อความหาลูกค้าที่เคยทัก (LINE) — เลือกได้ว่าจะให้ AI ปรับข้อความให้แต่ละคน

* ตัวเลขข้างบนมาจากกล่องข้อความจริงของคุณ — ส่วนยอดผู้ติดตาม/ยอดวิว/Engagement ต่อโพสต์ ต้องเชื่อม insights API ของแต่ละแพลตฟอร์ม (OAuth + รีวิว) ถึงจะดึงได้จริง
