===========================================
  วิธีใช้งาน Multi-Agent Agentic OS (ภาษาไทย)
===========================================

วิธีเปิดใช้งาน (ง่ายที่สุด)
---------------------------
1. ดับเบิลคลิกไฟล์ชื่อ  start.command

   * ครั้งแรกสุด: โปรแกรมจะเปิดไฟล์ .env ให้ใส่ API key
       - วางคีย์ ANTHROPIC_API_KEY ของคุณต่อท้ายเครื่องหมาย =
       - กด Command(⌘)+S เพื่อบันทึก แล้วปิดหน้าต่าง
       - ดับเบิลคลิก start.command อีกครั้ง
   * ครั้งต่อ ๆ ไป: ดับเบิลคลิกแล้วใช้งานได้เลย

2. โปรแกรมจะเปิดเบราว์เซอร์ให้เองที่  http://127.0.0.1:8000

3. พิมพ์เป้าหมายในช่อง "คำสั่งถึง CEO" แล้วกดส่ง
   ทีมเอเจนต์จะวางแผน ทำงาน และสรุปผลให้แบบสด ๆ


ถ้าดับเบิลคลิกแล้วขึ้นเตือนว่าเปิดไม่ได้ (จาก macOS)
--------------------------------------------------
- คลิกขวาที่ไฟล์ start.command -> เลือก "Open" -> กด "Open" อีกครั้ง
  (ทำแค่ครั้งแรกครั้งเดียว)


ข้อมูลถูกบันทึกอัตโนมัติ
------------------------
- ทุกบทสนทนา งาน สถานะ และผลลัพธ์ ถูกเก็บในไฟล์  agents.db
- เปิดโปรแกรมใหม่ ข้อมูลเก่ายังอยู่ครบ (ทำงานต่อจากเดิมได้)
- กดปุ่ม "+ New Session" เพื่อเริ่มเซสชันใหม่โดยไม่ลบของเก่า
- เลือกเซสชันเก่าจากเมนูดรอปดาวน์เพื่อดูประวัติย้อนหลัง


การปิดโปรแกรม
-------------
- กลับไปที่หน้าต่าง Terminal ที่เปิดอยู่ แล้วกด  Control + C
  หรือปิดหน้าต่างนั้นได้เลย
